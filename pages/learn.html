ריכוז נושאי הלימוד של המיקרו-בקר 8051 (C8051F380), עם הסבר על כל נושא, דוגמאות קוד בשפת C, ואילו רכיבים להשתמש בהם בסימולטור. מומלץ ללמוד לפי הסדר — קודם הבסיס (יציאות/כניסות), ואז המתקדם (פסיקות, מונים, תקשורת).

נושאי הלימוד

1. יציאות דיגיטליות 2. כניסות דיגיטליות 3. אנלוגי — קלט/פלט 4. פסיקות (Interrupt) 5. מונים (Timers) 6. תקשורת UART
איך לומדים? כל נושא כולל הסבר + דוגמת קוד. העתק את הקוד אל דף הסימולציה, בנה את המעגל עם הרכיבים המתאימים, ולחץ "הרץ". פירוט הרגיסטרים נמצא בדף הרגיסטרים.

1. יציאות דיגיטליות (Digital Outputs)

יציאה דיגיטלית היא פין שהבקר קובע את מצבו: '1' (מתח גבוה, ~3.3V) או '0' (מתח נמוך, 0V). כך מדליקים ומכבים רכיבים — נורית LED, זמזם, ממסר, מנוע.

איך כותבים ליציאה?

כותבים ערך לפורט שלם (8 פינים בבת אחת) או לפין בודד:

P1   = 0xFF;     // כל 8 הפינים של P1 → '1'
P1   = 0x00;     // כל הפינים → '0'
P1_0 = 1;        // רק הפין P1.0 → '1'  (מדליק נורית מחוברת אליו)
P1_0 = 0;        // P1.0 → '0'  (מכבה)

שליטה בפין בודד בלי לפגוע בשאר (אופרטורים ביטיים)

P1 |=  (1 << 3);   // הדלק רק את ביט 3   (OR)
P1 &= ~(1 << 3);   // כבה רק את ביט 3    (AND עם NOT)
P1 ^=  (1 << 3);   // הפוך את מצב ביט 3  (XOR)

דוגמה: נורית מהבהבת (Blink)

void main() {
    while (1) {
        P1_0 = 1;          // נורית דולקת
        delay_ms(500);     // המתן חצי שנייה
        P1_0 = 0;          // נורית כבויה
        delay_ms(500);
    }
}
בסימולטור: גרור LED, חבר רגל אחת לפין P1.0 של השבב ורגל שנייה ל-GND. הרץ — הנורית תהבהב.

2. כניסות דיגיטליות (Digital Inputs)

כניסה דיגיטלית היא פין שהבקר קורא ממנו את המצב: האם עליו מתח גבוה ('1') או נמוך ('0'). כך בודקים אם כפתור לחוץ, אם מתג פתוח/סגור, או מצב של חיישן דיגיטלי.

איך קוראים כניסה?

if (P2_0 == 1) {        // אם הפין P2.0 גבוה (למשל כפתור לחוץ)
    P1_0 = 1;           // הדלק נורית
} else {
    P1_0 = 0;           // אחרת כבה
}

דוגמה: כפתור מדליק נורית

void main() {
    while (1) {
        if (P2_0 == 1)      // כל עוד הכפתור לחוץ
            P1_0 = 1;       // הנורית דולקת
        else
            P1_0 = 0;       // משוחרר → כבויה
    }
}
בסימולטור: גרור כפתור ו-LED. חבר רגל של הכפתור ל-P2.0 ול-5V, ואת ה-LED ל-P1.0. לחיצה על הכפתור תדליק את הנורית.

מושג חשוב — ריבאונד (Debounce): מגע מכני של כפתור "מקפץ" אלפיות שנייה ויכול להיקרא כמה לחיצות. פתרון נפוץ: אחרי זיהוי לחיצה, להמתין מעט (delay_ms(20)) לפני שממשיכים.

3. יציאות וכניסות אנלוגיות (Analog I/O)

בניגוד לדיגיטלי (רק 0/1), אנלוגי הוא טווח רציף של ערכים. למשל פוטנציומטר שנותן מתח משתנה, או בהירות נורית שמשתנה בהדרגה.

כניסה אנלוגית — ממיר A/D (ADC)

הבקר ממיר מתח אנלוגי למספר דיגיטלי בעזרת ADC (ממיר אנלוגי-דיגיטלי) ברזולוציה של 10 ביט — ערכים 0 עד 1023. כך קוראים פוטנציומטר או חיישן אור. 

unsigned int v;
AD0EN  = 1;             // הפעל את הממיר
AD0INT = 0;
AD0BUSY = 1;            // התחל המרה
while (AD0INT == 0);    // המתן לסיום ההמרה
v = (ADC0H << 8) | ADC0L;   // התוצאה (0–1023)
✅ זה רץ באמת בסימולטור! גרור פוטנציומטר (או חיישן אור), הזז אותו, והרץ את הקוד — ה-ADC יקרא את הערך שלו ל-ADC0H:ADC0L בדיוק כמו בבקר אמיתי (0–1023).

פלט אנלוגי — PWM (אפנון רוחב פולס)

לבקר אין יציאה אנלוגית "אמיתית", אבל אפשר לחקות אותה ב-PWM: מדליקים ומכבים את הפין מהר מאוד, ויחס הזמן "דלוק/כבוי" קובע את ה"עוצמה" הממוצעת — בהירות נורית או מהירות מנוע. 

// בהירות ~50%: דלוק חצי מהזמן, כבוי חצי
while (1) {
    P1_0 = 1; delay_us(500);
    P1_0 = 0; delay_us(500);
}
בסימולטור: גרור פוטנציומטר או חיישן אור לקלט, ו-מנוע לפלט (הוא מציג מהירות לפי ערך הפורט). אפשר גם לראות את הערך במסך הצבעוני.

4. פסיקות (Interrupt)

פסיקה היא מנגנון שבו אירוע (לחיצת כפתור, גלישת מונה, קבלת נתון) "קוטע" את התוכנית הראשית, מריץ פונקציה מיוחדת (שגרת פסיקה — ISR), ואז חוזר בדיוק למקום שבו הופסק. היתרון: הבקר מגיב מיד לאירוע בלי לבזבז זמן בבדיקה מתמדת בלולאה (Polling).

סוגי פסיקות עיקריים

  • פסיקות חיצוניות — INT0 (פין P3.2), INT1 (פין P3.3) — מופעלות מאירוע חיצוני כמו כפתור.
  • פסיקות מונה — Timer 0 / Timer 1 — מופעלות בכל גלישת מונה.
  • פסיקת תקשורת — UART — בכל שליחה/קבלה של נתון.

איך מפעילים פסיקה? (3 שלבים)

  1. מאפשרים את הפסיקה הספציפית ברגיסטר IE (למשל EX0=1 ל-INT0).
  2. מדליקים את האישור הגלובלי: EA = 1.
  3. כותבים שגרת פסיקה עם המילה interrupt ומספר הפסיקה.
void main() {
    EX0 = 1;            // אפשר פסיקה חיצונית 0 (INT0)
    EA  = 1;            // אישור פסיקות כללי
    while (1) {
        // התוכנית הראשית רצה כרגיל
    }
}

// שגרת הפסיקה — רצה אוטומטית כשמתרחש אירוע על INT0:
void int0_isr() interrupt 0 {
    P1_0 = ~P1_0;       // הפוך את מצב הנורית בכל לחיצה
}
מקורמספרביט אישור
INT0 (חיצונית 0)0EX0
Timer 01ET0
INT1 (חיצונית 1)2EX1
Timer 13ET1
UART4ES

5. מונים (Timers / Counters)

מונה הוא רגיסטר שסופר אוטומטית פעימות שעון. כשהוא מגיע לערך המקסימלי הוא "גולש" (overflow) ומדליק דגל. שימושים: מדידת זמן מדויקת, יצירת השהיות, ספירת אירועים חיצוניים, ויצירת קצב לתקשורת.

הגדרת מונה

  • TMOD — קובע את אופן העבודה (8/13/16 ביט, טעינה-מחדש).
  • TH0, TL0 — הערך ההתחלתי / הנוכחי של המונה (בית גבוה ונמוך).
  • TR0 — מפעיל את המונה (1=רץ, 0=עצור).
  • TF0 — דגל גלישה (נדלק כשהמונה גלש).

דוגמה: השהיה בעזרת מונה 0

void main() {
    TMOD = 0x01;        // מונה 0 במצב 16 ביט
    while (1) {
        TH0 = 0x3C;     // ערך התחלתי (קובע את משך ההשהיה)
        TL0 = 0xB0;
        TR0 = 1;        // הפעל את המונה
        while (TF0 == 0);   // המתן עד שיגלוש
        TR0 = 0;        // עצור
        TF0 = 0;        // אפס את הדגל
        P1_0 = ~P1_0;   // הפוך נורית כל גלישה
    }
}
שילוב עם פסיקה: במקום להמתין ל-TF0 בלולאה, אפשר לאפשר ET0=1; EA=1; ולכתוב void t0() interrupt 1 { ... } שתרוץ אוטומטית בכל גלישה.

6. תקשורת UART (טורית)

UART היא תקשורת טורית — שולחים נתון ביט-אחרי-ביט על חוט אחד (TX לשליחה, RX לקבלה). כך הבקר מדבר עם מחשב, מודול Bluetooth, GPS, או בקר אחר. שני הצדדים חייבים לעבוד באותו קצב (Baud Rate), למשל 9600.

רגיסטרים עיקריים

  • SCON — שליטה: אופן עבודה ואישור קבלה (REN).
  • SBUF — חוצץ הנתונים: כתיבה אליו שולחת בית; קריאה מחזירה בית שהתקבל.
  • TI / RI — דגלי סיום שליחה / קבלת נתון.
  • הקצב נקבע בד"כ ע"י מונה 1 במצב טעינה-מחדש.

דוגמה: שליחת תו

void uart_send(unsigned char c) {
    SBUF = c;               // הכנס את הבית לחוצץ → שליחה מתחילה
    while (TI == 0);        // המתן עד שהשליחה הסתיימה
    TI = 0;                 // אפס את הדגל לקראת הבא
}

void main() {
    // (אתחול UART: SCON, TMOD, TH1 לקצב הרצוי)
    while (1) {
        uart_send('A');     // שלח את התו 'A'
        delay_ms(1000);
    }
}

דוגמה: קבלת תו

unsigned char uart_receive() {
    while (RI == 0);        // המתן עד שמתקבל בית
    RI = 0;                 // אפס את הדגל
    return SBUF;            // החזר את הבית שהתקבל
}
✅ זה רץ באמת בסימולטור! בדף הסימולציה יש חלון "טרמינל (UART)": כתיבה ל-SBUF מדפיסה בו תווים, וכשמקלידים טקסט בתיבת הקלט ולוחצים "שלח" — הקוד קורא אותו דרך SBUF כש-RI דולק. נסה תוכנית "הד" שמחזירה כל תו שמתקבל.
