📇 הרגיסטרים של ה-8051

הסבר בעברית על רגיסטרי הפונקציה המיוחדים (SFR — Special Function Registers) של הבקר C8051F380: מה כל רגיסטר עושה, ופירוט תפקיד כל ביט בו. הרגיסטרים הם ה"לוח בקרה" של הבקר — דרכם שולטים בפינים, בטיימרים, בפסיקות, בתקשורת ובממיר A/D.

איך ניגשים לביט בודד? כותבים שם_הרגיסטר.מספר_הביט, למשל P1.0 הוא הביט הנמוך של הפורט P1. אפשר גם בעברית של C עם sbit LED = P1^0;. הביטים ממוספרים מ-0 (הימני/הנמוך) עד 7 (השמאלי/הגבוה).

תוכן העניינים

יציאות (P0–P3) טיימרים TMOD TCON CKCON פסיקות IE IP IT01CF UART SCON0 ADC ADC0CN REF0CN PCA0CN SPI

יציאות וכניסות — פורטים P0–P3

לבקר ארבעה פורטים של 8 ביטים כל אחד. כל ביט הוא פין פיזי שיכול לשמש לפלט (הדלקת נורה, הפעלת מנוע) או לקלט (קריאת כפתור או חיישן).

פורטכתובת SFRביט-נגיששימוש
P00x80כן8 פינים P0.0–P0.7
P10x90כן8 פינים P1.0–P1.7
P20xA0כן8 פינים P2.0–P2.7
P30xB0כן8 פינים P3.0–P3.7
P1 = 0xFF;          // כל פיני P1 → '1' (פלט גבוה)
P1 = 0x00;          // כל פיני P1 → '0'
P1.0 = 1;           // רק הפין P1.0 גבוה
if (P2.3 == 0) { }  // קריאת כניסה: האם P2.3 לחוץ/נמוך?
בבקרי C8051F38x יש להגדיר את הפינים דרך ה-Crossbar ורגיסטרי PnMDOUT (Push-Pull / Open-Drain). אתחול זה נעשה לרוב בתוך Init_Device().

טיימרים (Timers)

הטיימרים סופרים פעימות שעון ומאפשרים מדידת זמן, יצירת השהיות מדויקות, ספירת אירועים ויצירת קצב תקשורת (Baud Rate). הם נשלטים ע"י TMOD, TCON ו-CKCON, וערכם נשמר בזוגות הרגיסטרים TH0/TL0, TH1/TL1.

TMOD — Timer Mode

0x89אופן עבודת הטיימרים

קובע את אופן הפעולה של טיימר 0 וטיימר 1. הבית מחולק לשניים: ארבעת הביטים העליונים לטיימר 1, והתחתונים לטיימר 0.

ביטשםתיאור
7GATE1שער טיימר 1 — כשהוא '1', הטיימר רץ רק כשהפין INT1 גבוה
6C/T1בחירת מקור: '0' = טיימר (פעימות שעון), '1' = מונה (פולסים מהפין)
5–4T1M1:0אופן טיימר 1 (ראה טבלת האופנים מטה)
3GATE0שער טיימר 0 (כמו GATE1, עבור INT0)
2C/T0בחירת מקור לטיימר 0: טיימר/מונה
1–0T0M1:0אופן טיימר 0
M1:M0אופןהסבר
00Mode 0מונה 13 ביט
01Mode 1מונה 16 ביט
10Mode 28 ביט עם טעינה-מחדש אוטומטית (auto-reload)
11Mode 3פיצול לשני מונים נפרדים (טיימר 0 בלבד)

TCON — Timer Control

0x88ביט-נגיש

מפעיל/עוצר את הטיימרים, מכיל את דגלי הגלישה (Overflow), ומגדיר את אופן ההפעלה של הפסיקות החיצוניות INT0/INT1.

ביטשםתיאור
7TF1דגל גלישת טיימר 1 — נדלק ע"י החומרה כשהטיימר עובר את הערך המקסימלי
6TR1הפעלת טיימר 1: '1' = רץ, '0' = עצור
5TF0דגל גלישת טיימר 0
4TR0הפעלת טיימר 0
3IE1דגל פסיקת INT1 — נדלק כשמתרחש אירוע על הפין INT1
2IT1סוג הפעלת INT1: '1' = לפי קצה יורד, '0' = לפי רמה נמוכה
1IE0דגל פסיקת INT0
0IT0סוג הפעלת INT0: קצה / רמה
TR0 = 1;            // הפעלת טיימר 0
while (TF0 == 0);   // המתנה עד שהטיימר יגלוש
TF0 = 0;            // איפוס הדגל ידנית

CKCON — Clock Control

0x8Eמקור שעון לטיימרים

בוחר את מקור השעון של כל טיימר — שעון המערכת המלא (SYSCLK) או שעון מואט (Prescaled).

ביטשםתיאור
7T3MHבחירת שעון לבית הגבוה של טיימר 3
6T3MLבחירת שעון לבית הנמוך של טיימר 3
5T2MHבחירת שעון לבית הגבוה של טיימר 2
4T2MLבחירת שעון לבית הנמוך של טיימר 2
3T1Mשעון טיימר 1: '1' = SYSCLK, '0' = שעון מואט (לפי SCA)
2T0Mשעון טיימר 0: '1' = SYSCLK, '0' = שעון מואט
1–0SCA1:0בורר ההאטה לטיימרים 0/1: 00=SYSCLK/12, 01=SYSCLK/4, 10=SYSCLK/48, 11=שעון חיצוני

פסיקות (Interrupts)

פסיקה מאפשרת לבקר להגיב מיד לאירוע (לחיצת כפתור, גלישת טיימר, קבלת נתון) בלי לבדוק אותו כל הזמן בלולאה. כדי שפסיקה תפעל צריך: (1) לאפשר אותה ב-IE, (2) להדליק את האישור הגלובלי EA, (3) לכתוב שגרת interrupt מתאימה.

IE — Interrupt Enable

0xA8ביט-נגיש

מאפשר או חוסם כל מקור פסיקה בנפרד. הביט EA הוא "מתג ראשי" — בלעדיו אף פסיקה לא תפעל.

ביטשםתיאור
7EAאישור פסיקות גלובלי — '1' מאפשר את כל הפסיקות שהופעלו
6ESPI0אישור פסיקת SPI0
5ET2אישור פסיקת טיימר 2
4ES0אישור פסיקת תקשורת טורית UART0
3ET1אישור פסיקת טיימר 1
2EX1אישור פסיקה חיצונית 1 (INT1)
1ET0אישור פסיקת טיימר 0
0EX0אישור פסיקה חיצונית 0 (INT0)
EX0 = 1;   // אפשר פסיקה חיצונית 0
EA  = 1;   // הדלק את האישור הגלובלי

IP — Interrupt Priority

0xB8ביט-נגיש

קובע עדיפות לכל פסיקה: '1' = עדיפות גבוהה, '0' = נמוכה. פסיקה בעדיפות גבוהה יכולה לקטוע פסיקה בעדיפות נמוכה.

ביטשםתיאור
6PSPI0עדיפות SPI0
5PT2עדיפות טיימר 2
4PS0עדיפות UART0
3PT1עדיפות טיימר 1
2PX1עדיפות פסיקה חיצונית 1
1PT0עדיפות טיימר 0
0PX0עדיפות פסיקה חיצונית 0

IT01CF — INT0/INT1 Configuration

0xE4בחירת פין וקוטביות

בוחר לאיזה פין יחוברו הפסיקות החיצוניות INT0/INT1 ובאיזו קוטביות (פעיל גבוה/נמוך).

ביטשםתיאור
7IN1PLקוטביות INT1: '0' = פעיל בנמוך, '1' = פעיל בגבוה
6–4IN1SL2:0בחירת פין ל-INT1 (0 = P0.0 … 7 = P0.7)
3IN0PLקוטביות INT0
2–0IN0SL2:0בחירת פין ל-INT0

תקשורת טורית — UART0

ה-UART שולח ומקבל נתונים בטור (פין אחד לשליחה, אחד לקבלה). קצב התקשורת (Baud Rate) נקבע ע"י טיימר 1 בדרך כלל. הנוסחה:

Baud Rate = (1/2) × (Overflow Rate of Timer 1)
Overflow Rate = T1CLK / (256 - TH1)

SCON0 — Serial Port 0 Control

0x98ביט-נגיש

שולט באופן הפעולה של ה-UART, מאפשר קבלה, ומכיל את דגלי השליחה/קבלה.

ביטשםתיאור
7S0MODEאופן: '0' = 8 ביט, '1' = 9 ביט
5MCE0אישור תקשורת רב-מעבדית
4REN0אישור קבלה: '1' = מאפשר קליטת נתונים
3TB80הביט התשיעי לשליחה
2RB80הביט התשיעי שהתקבל
1TI0דגל סיום שליחה — נדלק בחומרה, מאפסים בתוכנה
0RI0דגל קבלת נתון — נדלק כשהתקבל בית, מאפסים בתוכנה

SBUF0 — Serial Data Buffer

0x99חוצץ נתונים

רגיסטר הנתונים של ה-UART. כתיבה אליו מתחילה שליחה; קריאה ממנו מחזירה את הבית האחרון שהתקבל.

SBUF0 = 'A';            // שליחת התו 'A'
while (TI0 == 0); TI0 = 0;   // המתנה לסיום שליחה
char c = SBUF0;         // קריאת בית שהתקבל

ממיר אנלוגי-דיגיטלי (ADC0)

ה-ADC ממיר מתח אנלוגי (למשל מפוטנציומטר או חיישן אור) למספר דיגיטלי. לבקר ממיר 10 ביט (ערכים 0–1023).

ADC0CN — ADC0 Control

0xE8ביט-נגיש

מפעיל את הממיר, מתחיל המרה, ומכיל את דגל סיום ההמרה.

ביטשםתיאור
7AD0ENהפעלת הממיר: '1' = פעיל
6AD0TMאופן מעקב (Track) לפני המרה
5AD0INTדגל סיום המרה — נדלק כשההמרה הסתיימה (מאפסים בתוכנה)
4AD0BUSYעסוק / התחל: כתיבת '1' מתחילה המרה
3AD0WINTדגל השוואת חלון (Window Compare)
2–0AD0CM2:0בחירת מקור התחלת ההמרה (תוכנה / טיימר / פין)
AD0EN  = 1;            // הפעל ממיר
AD0INT = 0;
AD0BUSY = 1;           // התחל המרה
while (AD0INT == 0);   // המתן לסיום
unsigned int v = (ADC0H << 8) | ADC0L;   // קרא תוצאה (10 ביט)

ADC0CF — ADC0 Configuration

0xBCקצב ורזולוציה

קובע את שעון ההמרה (SAR clock) ואת רזולוציית הממיר.

ביטשםתיאור
7–3AD0SC4:0מחלק שעון ה-SAR — קובע את מהירות ההמרה מתוך SYSCLK
2AD08BEאופן 8 ביט: '1' = 8 ביט, '0' = 10 ביט
1–0—הגדרות נוספות (הגבר / יישור התוצאה)

REF0CN — Voltage Reference Control

0xD1מתח ייחוס

בוחר את מתח הייחוס (VREF) של הממיר ומפעיל את חיישן הטמפרטורה הפנימי ומקורות ההטיה.

ביטשםתיאור
4REFSLבחירת מקור מתח הייחוס: '1' = מתח ההזנה VDD, '0' = ייחוס פנימי / חיצוני
3TEMPEהפעלת חיישן הטמפרטורה הפנימי
2BIASEהפעלת מקור ההטיה הפנימי
1REFBEהפעלת חוצץ הייחוס הפנימי

דוגמה נפוצה: REF0CN = 0x10; בוחר את VDD (‎3.3V) כמתח ייחוס לממיר.

מערך מונים מתוכנת — PCA

PCA0CN — PCA Control

0xD8ביט-נגיש

ה-PCA (Programmable Counter Array) משמש ליצירת אותות PWM, מדידת זמן והשוואות. רגיסטר זה מפעיל את המונה ומכיל את דגלי המודולים.

ביטשםתיאור
7CFדגל גלישת מונה ה-PCA
6CRהפעלת מונה ה-PCA: '1' = רץ
4–0CCF4:0דגלי לכידה/השוואה של מודולים 0–4

ממשק SPI (SPI0)

SPI הוא ממשק תקשורת טורי-סינכרוני מהיר לחיבור התקנים (זיכרונות, חיישנים, צגים). הוא משתמש בקווי SCK (שעון), MOSI, MISO ו-NSS.

SPI0CFG — SPI0 Configuration

0xA1תצורה
ביטשםתיאור
7SPIBSYעסוק — העברה מתבצעת (קריאה בלבד)
6MSTENאופן Master: '1' = הבקר הוא ה-Master
5CKPHAפאזת שעון
4CKPOLקוטביות שעון
3–0—דגלי מצב (slave selected, shift empty וכו')

SPI0CN — SPI0 Control

0xF8ביט-נגיש
ביטשםתיאור
7SPIFדגל פסיקת SPI — נדלק בסיום העברה
6WCOLדגל התנגשות כתיבה
5MODFדגל תקלת אופן (Mode Fault)
4RXOVRNדגל הצפת קבלה
3–2NSSMD1:0אופן פין ה-NSS

SPI0CKR / SPI0DAT

0xA2 / 0xA3שעון ונתונים

SPI0CKR — מחלק קצב השעון: SCK = SYSCLK / (2 × (SPI0CKR + 1)).
SPI0DAT — רגיסטר הנתונים: כתיבה שולחת בית, קריאה מחזירה את הבית שהתקבל.
